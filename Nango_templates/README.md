# 難語ビューアー JSONテンプレート一覧

各バージョンに対応したインポート用JSONテンプレートです。  
配列形式（`[{...}, {...}]`）で記述してください。

---

## テンプレートとバージョン対応表

| テンプレートファイル | 対応バージョン | フィールド数 |
|---|---|---|
| `template_v01_v02_01.json` | v01_00 / v02_00 / v02_01 | 6 |
| `template_v02_02.json` | v02_02 | 8 |
| `template_v03_00_v03_01.json` | v03_00 / v03_01 | 11 |
| `template_v03_10_v04_xx.json` | v03_10 / v04_00 / v04_10 | 13 |

---

## フィールド追加の変遷

```
v01_00
  └─ word          語彙
  └─ meaning       意味
  └─ background    言葉の背景・由来
  └─ nuance        ニュアンス
  └─ examples[]    例文
  └─ synonyms[]    類義語

v02_02  ← 追加
  └─ id            管理用ID（自動採番されるので省略可）
  └─ category      カテゴリー（ツリー大分類）

v03_00  ← 追加
  └─ reading       よみがな（五十音ソートに使用）
  └─ kanji         漢字表記
  └─ english       英語・原語表記

v03_10  ← 追加
  └─ fieldTag      分野タグ（ツリー軸の切り替えに使用）
  └─ eraTag        時代タグ（同上）
```

---

## 注意事項

- **`id` は省略可能**。インポート時にアプリが自動採番します。同じIDが重複するとデータが意図せず上書きされる場合があるため、手動入力する場合は一意な値を設定してください。
- **古いバージョンへ新スキーマのJSONをインポートする場合**、未知のフィールドは無視されます（表示・保存されません）。
- **新しいバージョンへ古いスキーマのJSONをインポートする場合**、不足フィールドはアプリが空文字・空配列・デフォルト値で補完します。
- `examples` と `synonyms` は **文字列の配列** です。空エントリ（`""`）は削除してからインポートしてください。
