# 難語ビューアー (Nango Viewer)

日本語の難しい語彙・専門用語を体系的に管理・閲覧するための、**ゼロ依存の単一HTMLファイルアプリ**です。  
サーバー不要、インストール不要。ブラウザでHTMLを開くだけで動作します。

---

## 機能一覧

### 閲覧・検索
- **階層ツリー表示** — カテゴリー / 分野タグ / 時代タグの3軸で語彙を整理して左サイドバーに表示
- **キーワード検索** — 語彙名をリアルタイムで絞り込み
- **ソート** — 五十音順 / 登録順の切り替え
- **詳細カード表示** — 意味・言葉の背景と由来・ニュアンス・例文・類義語を右ペインに表示

### 編集
- **語彙の追加 / 編集 / 削除** — フォームUIからGUI操作のみで完結
- **タグ一括変更** — タグ管理パネルから分野タグ・時代タグの名称を一括リネーム

### データ管理
- **JSON エクスポート** — 登録データをJSONファイルとして保存
- **JSON インポート** — 既存JSONファイルを読み込んでデータを追加
- **localStorage 永続化** — ページを閉じてもデータが保持される
- **デフォルトリセット** — サンプルデータの状態に戻す

---

## 使い方

1. `Nango_v03_10.html` をブラウザで開く（ダブルクリックでOK）
2. 左サイドバーのツリーから語彙を選択して詳細を閲覧
3. ツールバーの **「新規追加」** ボタンから語彙を登録
4. データを保存したい場合は **「JSONエクスポート」** でファイルに書き出す

## データ構造（JSON形式）

```json
{
  "word":       "カスケード（cascade）",
  "meaning":    "連鎖的に物事が起きること。",
  "background": "語源・由来の説明。",
  "nuance":     "ニュアンスや使い方の補足。",
  "examples":   ["例文1", "例文2"],
  "synonyms":   ["類義語A", "類義語B"],
  "category":   "IT・テクノロジー",
  "fieldTag":   "ビジネス",
  "eraTag":     "現代"
}
```

| フィールド   | 型       | 説明                         | 必須 |
|------------|----------|------------------------------|------|
| `word`     | string   | 語彙（読み仮名や原語を含めてもよい） | ✅   |
| `meaning`  | string   | 端的な意味の定義               | ✅   |
| `background` | string | 語源・由来・歴史的背景          | —    |
| `nuance`   | string   | ニュアンスや使用上の注意        | —    |
| `examples` | string[] | 使用例文（複数可）             | —    |
| `synonyms` | string[] | 類義語・関連語（複数可）        | —    |
| `category` | string   | 大分類カテゴリー               | —    |
| `fieldTag` | string   | 分野タグ（ツリー整理に使用）    | —    |
| `eraTag`   | string   | 時代タグ（ツリー整理に使用）    | —    |
